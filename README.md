# 부동산 임장 앱 (imjang)

투자·실거주 겸용 부동산 현장 임장 기록 웹앱의 소스 스냅샷입니다.
Muse 호스티드 런타임(space-2)에서 빌드된 TypeScript 풀스택 앱입니다.

## 스택

- Frontend: React 19 + Leaflet(지도) + recharts(차트) + Tailwind CSS
- Backend: TypeScript 서버 액션 (호스티드 런타임)
- DB: SQLite + drizzle-orm (마이그레이션: `drizzle/`)
- 패키지 매니저: bun

## 주요 기능

- 지도에서 시·군·구 검색, 국토부 아파트 매매/전월세 실거래가 조회
- 매물 등록, 체크리스트 + 사진 기록, 내비 전송
- 단지/매물 비교 평가 모드, 최종 후보 선정
- 선정 후 실행: 재임장 검증 플랜, 임장 리포트(마크다운), 가격 추적, 매수 시뮬레이터
- 관심 단지 시세 트래킹 + 가격 변동 알림 (매일 자동 확인 예약)
- 임장 코스·동선 계획, 매물 단위 호가 기록, 음성 녹음 메모
- 내 주변 반경(2/5/10km) 아파트 실거래가 라벨

## 필요한 API 키

- 국토교통부 실거래가 API 키 (공공데이터포털, `MOLIT_API_KEY`): 매매/전월세 실거래가 조회
- VWorld 지도 API 키 (브이월드, 무료): 배경 지도 타일

## 중요 안내


- 이 스냅샷은 호스티드 런타임 전용 SDK(`@hatch/space-sdk`, `file:` 의존성)에
  결합되어 있어 그대로 Vercel 등에 배포할 수 없습니다.
  실제 서비스 배포는 별도 풀스택 코드베이스로 전환하는 것이 계획되어 있습니다.
- 아래 항목은 스냅샷에서 제외했습니다.
  - `app.db`: 사용자 데이터 + 서버에 저장된 API 키
  - `blobs/`: 사진·음성 녹음 파일
  - `node_modules/`, 빌드 산출물(`dist/`, `.space-build/` 등)
